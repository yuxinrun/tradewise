# 外贸业务 SOP（标准作业流程）

## 适用场景
团队培训与业务流程标准化。请根据自身业务特点修改后使用。

## 填写说明
每个流程明确：责任人、输入、动作、产出、时间要求。定期更新，避免流于形式。

## 注意事项
本 SOP 为业务参考，不构成法律文件。涉及合规、财务与合同的事项请遵循主管部门与专业机构要求。

---

## 1. 客户开发流程
- 责任人：业务员
- 输入：目标产品、目标市场、关键词库
- 动作：搜索潜在客户 → 背景核验 → 建立客户档案 → 个性化触达 → 记录跟进
- 产出：潜在客户名单、触达记录
- 时间要求：每工作日新增并整理一定数量线索

## 2. 询盘处理流程
- 责任人：业务员
- 输入：客户询盘
- 动作：分类（A/B/C/D）→ 24 小时内响应 → 提出关键问题 → 内部核算 → 报价审批 → 发送报价
- 产出：需求清单、报价单、跟进计划
- 时间要求：24 小时内首次响应

## 3. 订单执行流程
- 责任人：业务员 + 跟单
- 输入：双方确认的 PI / 合同
- 动作：定金确认 → 下达生产单 → 进度反馈 → 验货 → 单证准备 → 订舱报关 → 交单
- 产出：生产记录、验货报告、完整单证包、提单
- 时间要求：按合同交期倒排节点

## 4. 收款与财务流程
- 责任人：财务 + 业务员
- 输入：付款通知
- 动作：银行到账确认 → 核对付款方 → 结汇与申报 → 凭证归档
- 产出：到账记录、结汇凭证
- 时间要求：到账后及时确认并通知业务

## 5. 售后与复盘流程
- 责任人：业务员
- 输入：客户反馈
- 动作：响应 → 收集证据 → 判断责任 → 提出方案 → 执行 → 复盘改进
- 产出：客诉处理记录、供应商改进清单、订单复盘
