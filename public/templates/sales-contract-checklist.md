# Sales Contract 检查清单

## 适用场景
签署外贸销售合同前逐项核对。重大交易请由专业律师审核。

## 填写说明
逐项核对并根据实际情况补充。清单不构成法律意见。

## 注意事项
不同法域对合同条款的效力认定不同，争议解决方式尤其需要专业意见。

---

## 主体与基础条款
- [ ] 买卖双方全称、注册地址、联系方式准确
- [ ] 签约代表有权签署，公司名称拼写无误
- [ ] 合同编号、签署日期、生效条件明确

## 标的条款
- [ ] 品名、型号、规格、材质描述清晰
- [ ] 数量与计量单位明确
- [ ] 质量标准与验收方法具体（避免「符合行业标准」等模糊表述）
- [ ] 包装方式、唛头与标签要求明确

## 价格与付款
- [ ] 币种明确（USD/EUR 等）
- [ ] 单价、总价、价格条款含地点与 Incoterms 版本
- [ ] 付款节点、比例、到账定义清晰
- [ ] 银行信息准确，费用承担方明确
- [ ] 价格调整或有效期条款（如适用）

## 交付条款
- [ ] 交货时间、起算条件明确
- [ ] 装运港 / 目的地明确
- [ ] 运输方式与单据要求明确
- [ ] 延期交货的责任与处理方式

## 验货与合规
- [ ] 验货标准、时间与机构明确
- [ ] 认证与合规责任划分清晰
- [ ] 知识产权责任划分明确
- [ ] 不可抗力条款合理

## 违约与争议
- [ ] 违约责任与赔偿范围明确
- [ ] 争议解决方式与地点明确
- [ ] 适用法律明确
- [ ] 合同语言与文本效力说明
