# 出口流程检查表

## 适用场景
每笔出口订单执行过程中，按阶段逐项核对，避免遗漏关键环节。

## 填写说明
复制本文件到你的项目管理工具中，按订单填写负责人与完成日期。勾选状态建议在本地文档中维护。

## 注意事项
具体流程因地区、产品、贸易方式与业务模式而异，请结合海关、货代与银行的最新要求调整。

---

## 阶段 1：订单确认
- [ ] 客户真实性已验证（域名、邮箱、公司信息）
- [ ] 产品规格、数量、包装方式已书面确认
- [ ] 目标市场与认证要求已确认
- [ ] 价格条款含地点与 Incoterms 版本
- [ ] 付款方式与时间节点明确
- [ ] 合同 / PI 双方确认并归档

## 阶段 2：收款与生产
- [ ] 定金到账（以银行入账为准）
- [ ] 向供应商下达书面生产单
- [ ] 生产计划与预计完成日确认
- [ ] 中期验货安排（如适用）
- [ ] 包装设计与唛头确认

## 阶段 3：出货前
- [ ] 尾款到账或信用安排确认
- [ ] 商业发票、装箱单、合同信息一致
- [ ] 毛重、净重、体积来自实际测量
- [ ] 报关资料齐全，HS Code 有依据
- [ ] 订舱确认、截关时间与进仓地址核对
- [ ] 出货前验货完成

## 阶段 4：交付与后续
- [ ] 报关放行，提单信息核对无误
- [ ] 按约定方式交单
- [ ] 客户签收与到货反馈记录
- [ ] 收汇、结汇与申报凭证归档
- [ ] 客诉与异常记录归档
- [ ] 客户档案更新，订单复盘完成
