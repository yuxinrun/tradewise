## 一、业务背景：销售额不等于利润

一笔订单卖出 USD 10,000，看起来不错。但扣除采购、包装、物流、平台费、汇率损失与售后成本后，可能只剩几百元，甚至亏损。

新手最容易犯的错误是「只看售价、不算全成本」。这篇文章给你一套完整的利润核算方法，配合本站的外贸利润计算器使用。

## 二、利润核算的基本公式

```text
销售收入（人民币） = 销售单价（外币） × 汇率

总成本 = 采购成本 + 国内费用 + 出口费用 + 国际物流 + 保险
       + 平台/渠道费用 + 售后预留 + 其他成本

利润 = 销售收入 − 总成本 + 退税测算（如适用）

利润率 = 利润 ÷ 销售收入 × 100%
```

看起来简单，难点在于「不要漏项」。

## 三、成本项目清单

### 1. 采购成本

产品出厂价、模具费分摊、定制加工费、包装升级费。注意供应商报价是否含税，发票情况会影响退税与财务处理。

### 2. 国内费用

工厂到港口/仓库的运输、仓储、装卸、验货费、样品费分摊。

### 3. 出口费用

报关费、商检费、文件费、原产地证费用、代理服务费。

### 4. 国际物流

海运费/空运费、燃油附加费、目的港费用（如由你承担）、快递费、保险费。

### 5. 平台与渠道费用

B2B 平台年费分摊、交易佣金、广告费、独立站支付手续费、Amazon 佣金与 FBA 费用等。

<div class="warn">
<strong>重要：</strong>跨境平台的费率、佣金与仓储费会变化。核算时必须以平台官方最新收费说明为准，不要使用旧数据或他人经验值。
</div>

### 6. 隐性成本

- 汇率波动与银行手续费
- 退货与售后损耗
- 客户索赔与折扣
- 资金占用成本
- 样品与展会费用分摊

<div class="tip">
<strong>经验建议：</strong>在测算中预留 3%–8% 的隐性成本缓冲。不同品类差异很大，退货率高的品类要预留更多。
</div>

## 四、完整计算示例

以下为**模拟教学案例**，金额与汇率为教学设定，不代表真实市场数据。

一家企业出口 1000 件产品，售价 USD 8.5/件，汇率 7.15：

| 项目 | 单件金额（元） | 1000 件合计 |
| --- | --- | --- |
| 销售收入 | 60.78 | 60,775 |
| 采购成本 | 28.00 | 28,000 |
| 包装费 | 3.50 | 3,500 |
| 国内运输与报关 | 2.20 | 2,200 |
| 国际物流 | 9.80 | 9,800 |
| 保险 | 0.40 | 400 |
| 平台/佣金 5% | 3.04 | 3,039 |
| 售后预留 3% | 1.82 | 1,820 |
| 其他杂费 | 1.00 | 1,000 |
| 总成本合计 | 49.76 | 49,759 |
| 毛利 | 11.02 | 11,016 |
| 利润率 | 18.1% | — |

如果采购成本上涨 2 元，或汇率下降 0.1，利润会明显缩水。这就是为什么要在报价时留余量。

## 五、盈亏平衡分析

盈亏平衡价格是「利润刚好为零」的售价。公式：

```text
盈亏平衡售价（外币）
= (固定成本 − 退税测算) ÷ [汇率 × (1 − 平台费率)]
```

以上例计算（不含退税）：

- 固定成本 = 28 + 3.5 + 2.2 + 9.8 + 0.4 + 1.82 + 1 = 46.72 元
- 汇率 7.15，平台费率 5%
- 盈亏平衡售价 = 46.72 ÷ (7.15 × 0.95) = USD 6.88

当前售价 USD 8.5，高于盈亏平衡价，说明有安全空间。若客户压价到 USD 7.0，利润已经很薄。

## 六、退税怎么处理

出口退税涉及报关单、增值税专用发票、退税率与税务机关审核。不同产品的退税率不同，且政策可能调整。

<div class="warn">
<strong>不要编造：</strong>退税率必须以国家税务总局与主管部门公布的最新规定为准。本文示例中的退税率仅用于演示计算，不构成税务建议。具体申报请咨询专业财税人员。
</div>

在内部测算中，可以把退税作为「额外收益」而非「必然利润」。只有在资料齐全、申报通过后，才算真正实现。

## 七、汇率风险管理

- 报价时考虑汇率波动，缩短有效期或设置调整条款
- 收汇后结合自身资金需求决定结汇时点
- 大额长期订单可咨询银行关于汇率避险工具的使用
- 不要在内部核算中使用「理想汇率」

## 八、常见错误

<div class="warn">
<strong>1. 只按采购价 × 2 报价。</strong>忽略物流、平台费与售后，容易亏损。
</div>
<div class="warn">
<strong>2. 忽略隐性成本。</strong>退货、折扣、汇率损失都会吃掉利润。
</div>
<div class="warn">
<strong>3. 用旧的平台费率。</strong>平台政策变化快，必须以官方最新信息为准。
</div>
<div class="warn">
<strong>4. 把退税当成确定收益。</strong>申报条件与审核结果存在不确定性。
</div>
