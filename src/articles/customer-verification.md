## 一、业务背景：不是所有询盘都值得跟进

外贸业务员的时间有限。如果把所有询盘都当成同等重要的机会，你会把大量精力花在虚假询价、同行探价、学生作业和低质量客户身上。

客户验证的目的不是「挑客户」，而是**把有限的跟进资源投给更可能成交、风险更可控的对象**。这篇文章讲清楚验证信号、分级标准与实操流程。

<div class="tip">
<strong>基本态度：</strong>验证客户不是怀疑所有人，而是用可核查的信息降低误判。专业客户通常理解并接受适度的背景了解。
</div>

## 二、真实性验证的八个信号

### 1. 邮箱与域名

- 邮箱是否使用公司域名，而不是 Gmail、Yahoo 等免费邮箱（小公司使用免费邮箱并非绝对异常，但要结合其他信号）
- 公司域名是否与邮箱域名一致
- 域名注册时间是否过短（可用 WHOIS 查询）
- 邮箱签名是否完整，有无公司名、地址、电话

### 2. 公司官网

检查 About Us、Products、Contact 是否完整，产品是否与你的品类相关，图片是否为自有，内容是否有基本维护。一个长期不更新的模板站，可信度较低。

### 3. 公司注册信息

用目标国工商登记系统或第三方公开渠道核对公司名称、注册号、地址与经营状态。不同国家公开程度不同，查不到不一定虚假，但结合其他信号判断。

### 4. 社交媒体

LinkedIn 公司页是否有员工、动态与真实产品；Facebook / Instagram 是否有持续运营。空壳公司往往只有网站没有社交痕迹。

### 5. 询盘内容质量

高质量询盘通常包含具体规格、数量、目标市场、认证要求或应用场景。只问 "send me your best price" 且不愿提供任何信息的，需要谨慎。

### 6. 沟通专业性

对方是否使用公司邮箱、是否有清晰署名、是否回应具体问题。专业买家通常重视效率与信息准确。

### 7. 地址与电话

用 Google Maps 核对地址是否为真实办公场所或仓库。电话是否能接通，国家区号是否与目标市场一致。

### 8. 一致性与历史

公司名、网站、邮箱签名、社媒名称是否一致。搜索公司名 + scam / complaint 看是否有负面记录，但要注意区分竞争对手抹黑。

## 三、风险信号清单

<div class="warn">
<strong>出现以下情况时提高警惕：</strong>
</div>

- 使用免费邮箱，且拒绝提供公司网站或电话
- 公司的产品目录与你完全无关，却声称要大批量采购
- 询价内容极其笼统，却要求立即提供最低价
- 要求在第三国付款，付款人与公司名称不一致
- 要求先支付「保证金」「清关费」给个人或第三方账户
- 使用紧迫感施压：「今天不报价就给别人」
- 邮件中含可疑附件或要求点击陌生链接
- 地址在地图上不存在或为住宅/虚拟办公室
- 提供的银行信息频繁变更

## 四、客户分级标准

建议采用 A/B/C 三级：

| 级别 | 特征 | 跟进策略 |
| --- | --- | --- |
| A 类 | 信息完整、需求明确、公司真实、有决策权迹象、有合理时间表 | 优先 24 小时响应，提供定制方案，安排会议 |
| B 类 | 基本信息真实，但需求不够具体或决策链不清 | 标准回复 + 定期跟进，2–4 周一次 |
| C 类 | 信息不足、可疑信号较多、需求模糊 | 自动回复或低频跟进，不投入定制资源 |

<div class="tip">
<strong>动态调整：</strong>客户级别不是固定的。B 类客户给出具体规格后可升为 A 类；A 类客户长期失联可降为 C 类。每次沟通后都要更新记录。
</div>

## 五、验证流程（可复制）

```text
客户背景调查清单

基础信息：
[ ] 公司名与官网域名匹配
[ ] 邮箱为公司域名或已说明原因
[ ] 电话与地址可核查
[ ] LinkedIn 公司页与联系人存在

业务相关性：
[ ] 官网产品与询盘产品一致
[ ] 客户所在市场在目标范围内
[ ] 客户角色可能是采购/分销/零售

询盘质量：
[ ] 说明了规格或应用场景
[ ] 提供了数量或大致规模
[ ] 有明确的目标时间
[ ] 询问了认证、包装等细节

风险检查：
[ ] 无异常付款要求
[ ] 无可疑附件或链接
[ ] 无大量投诉记录
[ ] 付款方与公司名称一致（如进入付款阶段）

评分：真实性 ___/5  匹配度 ___/5  潜力 ___/5
结论：A / B / C
下一步：
```

## 六、模拟案例：识破一次虚假询盘（模拟教学案例）

以下为**模拟教学案例**，企业、邮箱与结果均为教学设定。

一位业务员收到邮件："We need 10,000 units, please send lowest price and PI immediately." 对方使用 Gmail 邮箱，没有署名，只有一句英文。

业务员没有立刻报价，而是回复了三个问题：规格、目标市场与公司名称。对方回复含糊，并催促先发 PI。进一步搜索发现：

- 对方声称的公司在网上无官网与社媒记录
- 邮箱签名中的电话区号与国家不符
- 要求付款到与公司名称无关的个人账户

结论：C 类，停止跟进。

<div class="warn">
<strong>教训：</strong>PI 是正式商务文件，不应发给未经核实的对象。虚假询盘常常以「紧急」为诱饵，目的是获取报价模板、公司信息或诱导后续欺诈。
</div>

## 七、另一个案例：B 类升级为 A 类

一家加拿大客户最初只发来一句产品咨询，使用公司邮箱但未写数量。业务员按 B 类处理，发送一份简洁目录并询问三个问题。客户两天后回复了具体规格、预计数量和清关要求。业务员将其升级为 A 类，安排产品会议，最终进入试单。

这说明：**不要因为第一封邮件简单就否定客户，也不要因为邮件热情就放松验证。**

## 八、常见错误

<div class="warn">
<strong>1. 用邮箱域名一票否决。</strong>部分小企业确实使用免费邮箱，要结合其他信号。
</div>
<div class="warn">
<strong>2. 过度验证导致失去客户。</strong>验证应在后台完成，不要让客户觉得被审问。
</div>
<div class="warn">
<strong>3. 把竞争对手当无效客户。</strong>同行也会询价，可以以专业方式应对，但不必透露核心客户与价格体系。
</div>
<div class="warn">
<strong>4. 验证一次就永久信任。</strong>付款阶段仍需重新核验银行信息，尤其是账号变更时。
</div>

## 九、FAQ

<details><summary>客户不愿意提供公司信息怎么办？</summary><div>可以礼貌说明：为了给出准确报价与方案，需要了解规格与市场。如果对方始终拒绝提供任何可核查信息，但要求正式文件或付款路径，建议谨慎处理。</div></details>

<details><summary>海关数据能验证客户吗？</summary><div>可以辅助判断客户是否有进口记录、采购来源与频次，但有滞后性与覆盖盲区，不能作为唯一依据。相关方法见《海关数据的使用方法与局限》。</div></details>

<details><summary>如何验证银行账户？</summary><div>通过银行官方渠道核对账户名是否与合同主体一致，任何账号变更都应通过已知电话回拨确认，而不是只依赖邮件。必要时咨询开户银行。</div></details>
