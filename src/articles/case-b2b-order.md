## 一、案例说明

**案例类型：模拟教学案例。** 本文中的企业名称、人物、金额、时间与结果均为教学设计，不对应任何真实企业或个人，也不构成收益承诺。

这个案例的目标是把前面学到的知识点串成一条完整链路：从一封询盘开始，到报价、签约、生产、验货、报关、收款与售后，展示每个阶段的关键决策与常见失误。

## 二、业务背景设定

一家中国浙江的工贸企业（下称「卖方」）生产家用收纳产品。一家波兰中型家居分销商（下称「买方」）正在寻找带 CE 相关测试报告的可折叠收纳箱供应商。

首单数量：3000 件。目标价格区间：FOB 宁波 USD 4.5–5.0。付款方式：30% 定金，70% 发货前付清。

## 三、阶段 1：询盘接收与识别（第 1 天）

买方发来邮件："We are looking for foldable storage boxes with test reports. Please send price for 3000 pcs."

卖方的动作：

<div class="steps">
<div class="step"><strong>4 小时内确认收到。</strong>不直接报价，而是说明会核实规格后提供正式报价。</div>
<div class="step"><strong>背景验证。</strong>搜索公司官网、LinkedIn 页面与域名信息，确认其主营家居分销，非同行探价。</div>
<div class="step"><strong>提出五个问题。</strong>尺寸、承重、面料、包装方式、是否需要 CE 相关测试报告。</div>
</div>

**关键决策：** 在信息不完整时不报价，避免后续返工。

**常见失误：** 直接回复 "Our best price is USD 4.2"，然后在客户提出具体规格后被迫改价。

## 四、阶段 2：报价与核算（第 2–3 天）

买方回复了规格：60×40×30cm，无纺布 + 木板支撑，定制彩盒，目标市场波兰。

卖方核算：

| 项目 | 金额（元/件） |
| --- | --- |
| 采购价 | 21.0 |
| 包装升级 | 3.0 |
| 国内运输与报关分摊 | 1.8 |
| 验货与杂费 | 0.8 |
| 国际物流（分摊） | 4.5 |
| 预留汇率与损耗 | 1.5 |
| 合计成本 | 32.6 |

按汇率 7.15 计算，FOB 成本约 USD 4.56。卖方报价 USD 4.88，有效期 15 天，写明 FOB Ningbo, Incoterms® 2020。

<div class="tip">
<strong>关键点：</strong>报价包含了所有可控成本与风险余量。若客户选择 CIF Gdansk，需重新计算运费与保险，不能直接沿用 FOB 价格。
</div>

## 五、阶段 3：谈判与签约（第 4–12 天）

买方还价 USD 4.60，并提到另一家供应商报价 USD 4.45。

卖方没有直接降价，而是提供了两个选项：

- 选项 A：维持彩盒包装，USD 4.82
- 选项 B：改为普通 PE 袋 + 贴纸，USD 4.58

买方选择了选项 B，因为该系列产品主走批发渠道，不需要高端彩盒。双方确认 PI：3000 件，USD 4.58，FOB 宁波，30% 定金，70% 发货前付清，交期 30 天（自定金到账且包装设计确认日起算）。

<div class="warn">
<strong>重要细节：</strong>交期起算条件写进了 PI。否则客户延迟确认包装设计时，工厂已经开始算交期，容易产生争议。
</div>

## 六、阶段 4：生产与验货（第 13–42 天）

- 第 13 天：定金到账，卖方向工厂下达生产单，附详细规格与包装确认稿。
- 第 16 天：工厂提供首件样品照片，卖方转发客户确认。
- 第 28 天：安排中期验货，发现面料色差略超确认样。
- 第 29 天：要求工厂更换面料批次，客户被同步告知进度影响。
- 第 40 天：生产完成，安排出货前验货，抽检合格。
- 第 42 天：装箱数据核对：3000 件，200 箱，每箱 15 件，毛重 12.5kg/箱，总体积 28.8 CBM。

**关键决策：** 发现色差后立即整改并同步客户，而不是等到出货前再解释延误。

## 七、阶段 5：报关与装运（第 43–47 天）

卖方准备 Commercial Invoice、Packing List、报关委托与合同：

1. 三单核对：品名、数量、金额、收货人、贸易术语一致。
2. HS Code 由报关行根据材质与用途归类，卖方保留归类依据。
3. 第 44 天报关申报，第 45 天放行。
4. 第 46 天装船，船公司签发提单。
5. 第 47 天卖方将提单副本发送给客户确认。

<div class="warn">
<strong>风险点：</strong>此阶段最容易出现单证不一致。本案例中，装箱单毛重来自实际称重而非估算，避免了运费补差争议。
</div>

## 八、阶段 6：收款与交付（第 48–75 天）

- 第 48 天：客户支付 70% 尾款，卖方确认银行实际到账。
- 第 49 天：寄送正本提单与全套清关单据。
- 第 68 天：货物到港，客户完成清关。
- 第 70 天：客户反馈到货情况，发现 2 箱外包装破损但内容物完好。
- 第 72 天：卖方提供破损照片给客户用于内部记录，并建议下一批加强外箱。
- 第 75 天：客户询问下一季度复购价格。

**关键决策：** 尾款到账后才放单，避免收款风险；客诉响应及时且保留证据。

## 九、全流程关键决策复盘

| 阶段 | 关键决策 | 如果做错会怎样 |
| --- | --- | --- |
| 询盘 | 先验证再报价 | 浪费时间或泄露价格体系 |
| 核算 | 计入包装升级与物流 | 报价偏低，订单亏损 |
| 谈判 | 用配置换价格 | 无底线降价或失去订单 |
| 合同 | 写明交期起算条件 | 延误责任不清 |
| 生产 | 中期验货 + 同步客户 | 批量质量问题或信任受损 |
| 单证 | 三单一致性核对 | 清关延误与额外费用 |
| 收款 | 到账后放单 | 货款两空风险 |
| 售后 | 快速响应并记录 | 复购机会流失 |

## 十、如果重来一次，可以做得更好的三件事

1. **询盘阶段就询问认证要求的具体标准。** CE 相关测试报告类型很多，本案例中后期才确认，增加沟通成本。
2. **在合同中约定色差接受标准。** 例如参照确认样与允差范围，减少主观判断。
3. **出货前拍照归档。** 外箱破损争议中，装柜前的照片能快速定位责任环节。

## 十二、FAQ

<details><summary>这个案例的数据可以直接参考吗？</summary><div>不可以。所有金额为教学设定，实际价格、成本与交期取决于产品、市场、供应链与谈判结果。案例的价值在于流程与决策逻辑，而不是具体数字。</div></details>
