## 一、业务背景：单证错了，货可能到不了

外贸单证不是行政手续，而是交易与物流的语言。客户用它清关，银行用它审核付款，海关用它判断申报是否真实。

新手最常见的单证问题不是不会做，而是**不知道每份单证的用途，导致信息复制粘贴后互相矛盾**。这篇文章讲清楚四类核心单证的用途、内容要点与核对方法。

## 二、四类单证分别解决什么问题

| 单证 | 英文 | 主要用途 | 使用阶段 |
| --- | --- | --- | --- |
| 形式发票 | Proforma Invoice (PI) | 报价确认、订单确认、客户申请付款 | 成交前后 |
| 商业发票 | Commercial Invoice | 清关、计税、付款依据 | 出货与清关 |
| 装箱单 | Packing List | 说明包装、数量、重量与体积 | 出货与清关 |
| 销售合同 | Sales Contract | 明确双方权利义务与争议解决 | 成交阶段 |

<div class="note">
<strong>重要区分：</strong>PI 常被当作订单确认文件使用，但不等同于商业发票。Commercial Invoice 是实际交易与清关用的正式发票。两者内容应一致，但用途不同。
</div>

## 三、Proforma Invoice 的关键内容

一份 PI 通常包含：

1. 卖方与买方完整信息
2. PI 编号、日期、有效期
3. 产品描述、规格、数量、单价与总价
4. 价格条款（FOB/CIF 等 + 地点 + Incoterms® 2020）
5. 包装、交期、付款方式
6. 银行信息
7. 备注：包含项、不含项、验货标准

<div class="tip">
<strong>实务建议：</strong>PI 中的产品描述要与客户后续清关用的描述保持一致。不要为了「好记」而随意简化品名。
</div>

## 四、Commercial Invoice 的关键内容

商业发票是海关判断货值、品名与贸易性质的重要依据，通常包括：

- 买卖双方名称与地址
- 发票编号与日期
- 合同号 / 订单号
- 产品描述、HS Code（如客户要求）
- 数量、单价、总价与币种
- 原产国
- 贸易术语
- 运费、保险费等分项（如适用）
- 卖方签章

<div class="warn">
<strong>红线：</strong>不得低报或虚报货值，不得虚构品名或原产国。此类行为可能导致补税、罚款、货物扣留，甚至法律责任。申报金额应与实际交易一致。
</div>

## 五、Packing List 的关键内容

装箱单回答「货是怎么装的」：

| 字段 | 说明 |
| --- | --- |
| 箱号 | 每箱唯一编号，如 1/20, 2/20 |
| 品名与规格 | 该箱内货物明细 |
| 每箱数量 | 便于客户核对 |
| 净重 / 毛重 | 影响运费与清关 |
| 箱规 | 长宽高，用于计算 CBM |
| 总页数 | 便于发现缺页 |

装箱单数据必须来自实际称重与量尺，而不是估算。毛重与体积错误会导致运费补差或客户收货差异投诉。

## 六、Sales Contract 的关键条款

销售合同比 PI 更正式，通常包含：

- 合同主体与签约代表
- 标的物：品名、规格、数量、质量标准
- 价格与价格条款
- 付款方式与时间节点
- 交货时间、地点与运输方式
- 包装与唛头
- 检验与验收
- 违约责任
- 不可抗力
- 争议解决方式与适用法律
- 生效条件与份数

<div class="warn">
<strong>法律提醒：</strong>合同模板仅为业务参考，不构成法律意见。金额较大、条款复杂或首次合作的交易，应由专业律师审核。
</div>

## 七、三单一致性核对

出货前最重要的核对原则：**PI / Contract、Commercial Invoice、Packing List 中的关键信息一致**。

```text
三单一致性检查表

[ ] 买卖双方名称与地址一致
[ ] 产品品名与规格一致
[ ] 数量一致
[ ] 单价与总金额一致（发票与合同）
[ ] 币种一致
[ ] 贸易术语一致
[ ] 目的港/目的地一致
[ ] 包装方式与箱数一致
[ ] 毛重、净重、体积与装箱单一致
[ ] 日期逻辑合理（合同 → PI → 发票 → 装箱）
```

<div class="tip">
<strong>为什么重要：</strong>海关与客户会根据这些单据判断交易真实性。一处不一致，就可能导致清关卡住或客户拒付。
</div>

## 八、模拟案例：一处地址不一致的代价（模拟教学案例）

以下为**模拟教学案例**，企业、金额与结果均为教学设定。

一家出口商向意大利客户发货，Commercial Invoice 上的买方地址写成了客户的旧办公室，而 Packing List 上写的是新仓库地址。货物到港后，海关要求补充说明，客户也被迫提供额外文件，清关延误 4 天，产生仓储费。

问题不在于地址本身，而在于**单证之间不一致**。如果三份文件都写旧地址，且客户提前确认过，通常不会引发同样问题。

## 九、常见错误

<div class="warn">
<strong>1. 从旧文件复制忘记改。</strong>客户名、日期、港口、数量是最常见的遗留错误。
</div>
<div class="warn">
<strong>2. 品名过于笼统。</strong>"Goods" "Parts" 这类描述无法满足清关要求。
</div>
<div class="warn">
<strong>3. 重量体积靠估算。</strong>导致运费争议与客户收货差异。
</div>
<div class="warn">
<strong>4. 忽略客户清关要求。</strong>某些国家要求特定字段、认证编号或原产地声明，应提前确认。
</div>

## 十、FAQ

<details><summary>PI 和 Commercial Invoice 金额可以不同吗？</summary><div>原则上应一致。如因价格调整、运费变化等原因不同，必须有双方书面确认并能解释差异，否则可能引发清关与收款问题。</div></details>

<details><summary>装箱单必须盖章吗？</summary><div>取决于客户与目的国要求。很多情况下签名即可，但有些清关场景需要盖章。按客户与货代要求执行。</div></details>

<details><summary>HS Code 必须写在发票上吗？</summary><div>并非所有国家强制要求，但很多客户和报关行会要求提供。应按实际归类填写，并与报关申报一致。归类以海关规定为准。</div></details>
